DONNÉES ET VIE PRIVÉE

Politique de confidentialité

Cette politique décrit le fonctionnement actuel du site statique. Elle devra être révisée si de nouveaux services, formulaires, journaux d’audience ou publicités sont activés.

Calculs et données saisies

Les calculs sont effectués dans votre navigateur. Le site ne transmet pas les valeurs du calculateur à un serveur applicatif. La fonction de partage place les paramètres non sensibles dans l’URL : toute personne à qui vous transmettez ce lien pourra les consulter. N’incluez aucune donnée personnelle ou confidentielle dans les noms d’appareils.

Stockage local facultatif

Le site n’enregistre pas les simulations automatiquement. Le bouton « Enregistrer sur cet appareil » écrit les valeurs choisies dans le stockage local du navigateur (localStorage) après votre action. Ces données restent sur le navigateur et l’appareil utilisés, sous réserve de leurs réglages. Elles ne sont pas synchronisées ni envoyées à WattCombien. Effacez-les via les paramètres de stockage du navigateur ; la limite de conservation dans l’interface est de 20 dernières simulations.

Le choix de thème est également mémorisé localement après changement. Si le stockage local est bloqué, certaines préférences ou l’enregistrement peuvent ne pas être disponibles.

Fonctions du navigateur

La copie des résultats sollicite le presse-papiers après activation du bouton. L’export CSV crée un fichier sur votre appareil. Le partage par URL peut apparaître dans l’historique, les journaux du navigateur ou être transmis à des tiers si vous envoyez le lien.

Traceurs, statistiques et publicité

La version fournie ne charge ni outil d’analyse, ni traceur publicitaire, ni script AdSense, ni CMP. Aucun bandeau de consentement fictif n’est affiché. L’hébergement GitHub Pages peut produire des journaux techniques selon les conditions de l’hébergeur ; consultez les informations de GitHub applicables.

La monétisation est désactivée par défaut. Avant d’activer des annonces, l’éditeur doit configurer une CMP appropriée aux exigences applicables en France et dans l’EEE, vérifier les obligations de consentement et de transparence selon les technologies réellement utilisées, mettre à jour cette politique, renseigner l’identifiant éditeur réel et faire approuver le site. Aucun identifiant n’est prérempli ici.

Contact et droits

Les coordonnées de l’éditeur et les moyens d’exercer vos droits doivent être complétés dans les mentions légales avant publication. La page contact indique le canal actuellement disponible.
